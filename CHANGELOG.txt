--------------------------------------------------------------------------------
2026-02-20  Save Selection as Molecule 機能の追加
--------------------------------------------------------------------------------

[新規ファイル]
  source/gui/save_molecule_dialog.py
    - ASE GUI で選択した原子から分子定義 TOML (data/<name>.toml) を作成する
      ダイアログを実装
    - find_equivalent_molecules(): 選択した分子と等価な分子をユニットセル内
      から自動検出（ペア間距離の比較による構造マッチング）
    - _format_toml(): 既存の data/benzene.toml 等と同じ形式で TOML 文字列を生成
    - SaveMoleculeDialog (BaseDialog 継承):
        - molecule_name テキスト入力
        - 選択原子の一覧テーブル (Index / Elem / X / Y / Z)
        - インデックスの手動追加 (カンマ・スペース区切り、範囲指定 "3-7" に対応)
        - テーブルから選択行を削除する Remove Selected ボタン
        - 等価分子の自動検出チェックボックス
        - 検出された分子の重心 (COM) 一覧表示
        - 出力フィールド: molecule_name, symbols, use_fractional, positions,
          lattice_vectors, num_molecules, center_of_mass
        - positions は第1分子の COM 基準の相対座標
        - center_of_mass は ASE の get_center_of_mass() による実座標を保持

[変更ファイル]
  molecular_modeling_gui.py
    - import 追加: source.gui.save_molecule_dialog.show_save_molecule_dialog
    - save_molecule_dialog() メソッド追加:
        選択原子のインデックス取得 → バリデーション → ダイアログ呼び出し
    - MoleculeTools メニューに "Save Selection as Molecule..." 項目を追加
      ("List Molecules/Groups" の直後)

[設計方針]
  - BaseDialog / LabeledEntry (base_dialog.py) のパターンを踏襲
  - scipy.spatial.distance.pdist (既存依存) を利用した等価分子検出
  - tomllib は読み取り専用のため、TOML 出力は手動文字列生成
  - COM 計算は ASE の Atoms.get_center_of_mass() を使用
