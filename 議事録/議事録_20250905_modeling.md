* 進捗
  * 現状について
    * 重なり部分を最大にする最適化の実装終了(野田)
    * おおまかな流れは以下の通り
      * 辞書ファイルより全系の初期構造を計算
        辞書ファイルと全系のボロノイセルを計算
        分子の角度を最適化
        ボロノイセル描画(最適化確認用)
        VESTA, Quantum Espresso、VASP用ファイルの作成(野田)
      * 順番に説明する(野田)
  * 分子の角度の最適化(1)
    * 辞書ファイルからのものと全系からのボロノイセルの重なりを最適化(野田)
    * IoU(Intersection over Union) を用いる(野田)
      物体検出やセグメンテーションのタスクで用いられている(野田)
      0から1の値
  * 分子の角度の最適化(2)
    * ボロノイセルの重なりを角度の関数とした場合に特異点があるので微分を用いる最適化ルーチンが使えない(野田)
      ODAT-SEにも採用されている以下の方法を用いる(野田)
      * grid ベース
      * Nelder-Mead法
  * ボロノイセルの体積の計算
    * 辞書ファイルのボロノイセル
      分子結晶は向きが変わるのみで形状は変わらない(野田)
    * 全系のボロノイセル
      向きも形状も変わらない(野田)
    * 重なり部分の体積
      * 以下の格子点からボロノイセルを作成し、その体積が重なり部分の体積に一致
        * 分子の重心位置を格子点としてもの
        * 全系の配置した分子の重心を格子点としてもの
    * scipy の Voronoi と trimesh を用いている
      * 非周期系なので、a, b, c方向についてレプリカで体積を増やして計算している(野田)

  * 最適化の結果(1)
    * 標準出力により回転した角度が分かる(野田)
  * 最適化の結果(2)
    * pngファイルも出力できる(野田)
      Site 0 (benzene) と Site 1 (naphtalene) でオーバラップが確認できる(野田)

  * コードの使用方法
    * ファイルが7つほど多くなったので、実行方法が変わった(野田)
      * 実行: $ python run.py
      * requirements.txt によって pip で必要なパッケージをインストール可能(野田)
    * Mac mini(M1)で20秒程度(野田)
