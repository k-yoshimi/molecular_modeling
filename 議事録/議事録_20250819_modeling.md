# 議事
* 進捗
  * 基本機能の追加

        * 炭素を水素に置換するなど(野田)
      * リスト表記による、ある分子内に含まれる原子の一括置換
        * ベンゼン(C6H6)があって、それをまとめて置換したい場合(野田)
    * 設計書v0.3
      * モデリングツール全体の構造
        * 全領域のある原子から別の原子への一括置換を実装しました(野田)
        * リスト表記による、分子内の全原子一括置換を実装しました(野田)

  * 分子結晶のボロノイセルと辞書ファイルの変更
    * 回転にとりかかった(野田)
    * 結晶のボロノイセルと分子のボロノイセルの重なりを最大にするように回転(野田)

    * 分子結晶のcifファイルでは、結晶に分子が複数個ある事がある
      * ユニットセルにベンゼンが2個あったりする
        ボロノイセルを計算して体積を計算したい
        なので、辞書ファイルに分子結晶の情報(格子ベクトル、分子の数、重心)を追加(野田)

  * ボロノイセル計算ライブラリの選定、調べた限りでは3つの方法がある(野田)
    * SciPy + Trimesh
      * 実装が容易だが、孤立系なので周囲にレプリカのセルが必要
        scipyは標準的(野田)
    * pyvoro
      * 周期系を扱えるが、Python3.10以下のみに対応
        更新が止まっている(野田)
    * Voro++
      * 周期系を扱え、計算スピードが速いが、C++の環境構築が苦労するように見える(野田)
    * Python 3.11以上でも使え、C++の環境を必要としないSciPy + Trimeshで実装

  * 分子結晶のボロノイセル計算結果
    * ベンゼン分子結晶のボロノイセルを作成
      * 妥当な結果
        ボロノイセルの体積がユニットセル体積の半分で等しい事も確認済み(野田)
