GUI 操作ガイド
==============

Molecular Modeling GUI は ASE-GUI を拡張したグラフィカルインターフェースです。
分子の追加、置換、エクスポートなどの操作をインタラクティブに行えます。

起動方法
--------

.. code-block:: bash

   # 空の構造で起動
   python molecular_modeling_gui.py

   # 既存の構造ファイルを指定して起動
   python molecular_modeling_gui.py structure.cif

   # CIF ビューアとして起動
   python vis_cif.py structure.cif

   # パイプラインから GUI を起動（edit_and_run.py）
   python edit_and_run.py

ウィンドウ構成
--------------

GUI ウィンドウは以下の要素で構成されます:

1. **ファイルパネル（上部）**: アイコンボタン群（後述）
2. **3D ビューポート**: 分子構造の表示（回転・並進・ズーム可能）。左下に XYZ 座標軸インジケータ表示
3. **ツールバー**: Translate / Rotate / Zoom ボタン
4. **ボトムパネル**: Molecule Tools / Structure Tools のアイコンボタン群
5. **サイドパネル（右側）**: ビュー設定、Element Controls、Molecule Controls（折りたたみ可能）
6. **ステータスバー**: 選択中の原子情報

ウィンドウサイズの変更
~~~~~~~~~~~~~~~~~~~~~~

**View Settings** メニューからウィンドウサイズを変更できます:

- **Small (450x450)**: コンパクト表示
- **Medium (700x700)**: 標準サイズ（デフォルト）
- **Large (1000x800)**: 大画面表示
- **Wide (1200x600)**: 横長表示
- **Custom Size...**: 任意のサイズを指定

ウィンドウの境界をドラッグしてサイズを変更することもできます。

ボトムパネル
~~~~~~~~~~~~

3D ビューポートの下側に配置されたアイコンボタン群です。

- **Molecule Tools**: Select（選択）/ Move（移動）/ Rotate（回転）/ Delete（削除）/ Drag（ドラッグモード）
- **Structure Tools**: Add Molecule / Substitution / Supercell / Cell Parameters

Pipeline メニュー
~~~~~~~~~~~~~~~~~

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - メニュー項目
     - 説明
   * - Run Optimize (Voronoi) (Ctrl+P)
     - 現在の構造に対して Voronoi IoU 最適化を実行。結果（IoU 値、Euler 角）がダイアログに表示される
   * - Run Render (Voronoi PNGs)...
     - Voronoi セルオーバーレイの 3D 可視化 PNG を生成
   * - Run Export (QE, VASP, CIF)...
     - 構造ファイルを指定ディレクトリにエクスポート
   * - Run All (Optimize → Render → Export)...
     - 最適化 → 可視化 → エクスポートの全パイプラインを一括実行
   * - Show Optimization Results... (Ctrl+H)
     - 最適化結果（IoU 値、Euler 角、スケール）をテーブル形式で表示。CSV エクスポートおよび Voronoi PNG の閲覧も可能

**注意**: Pipeline メニューの各操作は ``mol_id`` 情報を持つ構造（TOML から構築した構造）に対してのみ実行できます。
処理はバックグラウンドスレッドで実行されるため、GUI は操作中もフリーズしません。

ビュー操作ツールバー
--------------------

3D ビューポートの下部にあるツールバーで、表示を操作できます。
各ボタンは押し続けることで連続的に操作できます。

.. list-table::
   :header-rows: 1
   :widths: 20 30 50

   * - セクション
     - ボタン
     - 説明
   * - Translate
     - ◀ ▶ ▲ ▼
     - ビューを上下左右に移動
   * - Rotate
     - X- X+ Y- Y+ Z- Z+
     - X/Y/Z 軸周りに ±5° 回転
   * - Zoom
     - \- +
     - 拡大・縮小
   * - BG Color
     - White / Black / Dark / Light / Custom
     - 背景色のプリセット変更またはカスタム色の選択
   * - Actions
     - ↩ ↪ ✖ |move| ↻
     - Undo / Redo / 選択原子の削除 / 移動 / 回転（各ボタンにツールチップ付き）
   * - Drag
     - |hand|
     - ドラッグモード切り替え: 有効時、選択した原子をマウスドラッグで直接移動

ツールチップ
~~~~~~~~~~~~

すべてのツールバーボタンにはツールチップ（マウスホバー時のフローティングヘルプ）が表示されます。
ボタンの上にマウスカーソルを置くと、操作内容やキーボードショートカットが黄色のポップアップで表示されます。

サイドパネル
~~~~~~~~~~~~

ウィンドウ右側にサイドパネルが表示されます。よく使うビュー設定にすばやくアクセスできます。
パネルは **マウスホイール** で上下スクロールが可能です。内容がウィンドウに収まらない場合もスクロールして操作できます。

- **Focus / Unfocus**: フォーカスモードの開始/終了ボタン
- **Color Mode**: 色分けモードをラジオボタンで切り替え（元素別 / 分子グループ別 / タグ別）
- **Show Bonds**: ボンド（結合線）の表示/非表示チェックボックス (Ctrl+B)
- **3D Spheres**: 3D シェーディング球体レンダリングの有効/無効
- **Element Controls** *(折りたたみ可能)*: ヘッダーをクリックで展開/折りたたみ。元素ごとに [表示チェック][色スウォッチ][サイズスライダー] を一行で制御。全原子サイズスケールのスライダー（0.3〜3.0）も含む
- **Molecule Controls** *(折りたたみ可能)*: ヘッダーをクリックで展開/折りたたみ。分子グループごとに [表示チェック][色スウォッチ][選択ボタン] を一行で制御。 **フォーカスモード中** はチェックボックスがフォーカス対象の追加/除去として機能
- **Atom List** *(折りたたみ可能、デフォルトは折りたたみ)*: ヘッダーをクリックで展開。全原子のインデックス(#)、元素、X/Y/Z座標、分子グループIDを表示するテーブル。行をクリックすると3Dビューでその原子を選択
- **ステータス情報**: 原子数、選択数、元素内訳、グループ数をリアルタイム表示

サイドパネルは **View Settings** → **Toggle Side Panel** で表示/非表示を切り替えられます。

ステータスバー
--------------

画面下部のステータスバーには、選択状態に応じた情報が表示されます。

- **原子未選択時**: 全体情報 — 原子数、含有元素、分子グループ数、セルサイズ
  (例: ``48 atoms | (C, H) | 4 groups | Cell: 5.5x5.4x18.7 Å``)
- **1原子選択時**: 原子詳細 — インデックス、元素名、座標、所属分子名
  (例: ``#3 Carbon (C): 1.114, 0.098, 0.812 Å | mol_id=0 (benzene)``)
- **2原子選択時**: 原子間距離（MIC 補正済み）、所属分子名
  (例: ``#0(C)-#6(H): 1.089 Å | benzene``)
- **3原子選択時**: 結合角度（MIC 補正済み）、所属分子名
  (例: ``#0(C)-#1(C)-#2(C): 120.0° | benzene``)
- **4原子選択時**: 二面角（MIC 補正済み）

測定結果は自動的にログに記録され、 **MoleculeTools** → **Measurement Log...** で一覧を確認できます。

マウス操作
----------

ASE-GUI 標準のマウス操作に加え、右クリックコンテキストメニューが使用できます:

- **左クリック**: 原子を選択
- **Shift + 左クリック**: 選択に追加
- **Ctrl + 左クリック**: 選択を反転
- **右クリック**: コンテキストメニュー表示（Select Molecule Group / Move / Rotate / Delete）
- **左ドラッグ**: ビューの回転
- **右ドラッグ** (または Shift + 右ドラッグ): ビューの並進
- **マウスホイール**: ズーム

座標軸インジケータ
~~~~~~~~~~~~~~~~~~

3D ビューポートの左下に XYZ 座標軸インジケータが表示されます。
現在のビュー回転に合わせて軸方向がリアルタイムに更新され、構造のどの方向を見ているか常に確認できます。
各軸はカラーコード化されています: **X** = 赤、**Y** = 緑、**Z** = 青。

右クリックコンテキストメニュー
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

3D ビューポートで右クリックすると、以下の操作にすばやくアクセスできます:

- **Select Molecule Group**: クリック位置の原子が属する分子グループ全体を選択
- **Move...**: 移動ダイアログを表示
- **Rotate...**: 回転ダイアログを表示
- **Delete Selected**: 選択中の原子を削除
- **Delete Molecule**: 選択中の原子が属する分子を削除

スクリーンショット
~~~~~~~~~~~~~~~~~~

**Ctrl+Shift+S** または ファイルパネルのカメラアイコンで、現在の 3D ビューを PNG ファイルとして保存できます。
Pillow がインストールされている場合は PNG 形式、未インストールの場合は EPS 形式で保存されます。

ダイアログ詳細
--------------

Focus Selection ダイアログ
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

原子を選択した状態で **Focus on Selection** (Ctrl+F) を実行すると、プレビューウィンドウが表示されます。

ウィンドウは **非モーダル** で、メイン画面での原子クリックが可能です。

- **3D プレビュー** (上部): フォーカス対象の原子がカラー表示、非対象は薄いグレーで表示。マウスで回転・ズーム可能
- **ステータス**: フォーカス中の原子数を表示
- **Unit**:

  - **Atom**: 個別の原子単位で追加/除去
  - **Molecule**: クリックした原子が属する分子グループ全体で追加/除去

- **Molecules**: 各分子グループがチェックボックスと色スウォッチで表示される。チェックの ON/OFF でフォーカスセットに追加/除去

**自動トグル動作**:

メイン画面では、現在のフォーカス対象が選択状態（ハイライト）で表示されます。
Add/Delete モードの切り替えは不要で、クリックするだけで自動的にトグルされます：

- フォーカス **外** の原子をクリック → フォーカスに **追加**
- フォーカス **中** の原子をクリック → フォーカスから **除去**

通常のクリック、Ctrl+クリック、Shift+クリックのいずれでも動作します。

**操作例**:

1. 原子を選択して Focus → 選択原子の所属分子がプレビューに表示され、メイン画面でフォーカス対象がハイライト
2. Unit を Molecule にして別の原子をクリック → その分子がプレビューに追加、メイン画面のハイライトも更新
3. Unit を Atom にしてフォーカス中の特定の原子をクリック → その原子だけ除去
4. ダイアログの Molecules チェックボックスでも分子単位で追加/除去が可能
5. OK でフォーカスモードに確定、Cancel で元の状態に復元

**フォーカスモード中のサイドパネル操作**:

フォーカスモード中は、サイドパネルの Molecule Controls のチェックボックスがフォーカス対象の追加/除去として機能します：

- チェックを入れる → その分子をフォーカスに追加して表示
- チェックを外す → その分子をフォーカスから除去して非表示

Add Molecule ダイアログ
~~~~~~~~~~~~~~~~~~~~~~~

- **Molecule**: ドロップダウンから ``data/*.toml`` に定義された分子を選択
- **Position (X, Y, Z)**: 配置位置をデカルト座標で入力
- **Add Mode**:

  - **Single**: 1 つの分子を指定位置に追加
  - **Unit Cell**: 分子定義の全分子を一括追加（格子ベクトルも設定）

- **3D Preview**: 選択した分子のプレビュー表示

Save Selection as Molecule ダイアログ
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. 3D ビューポートで原子を選択（Shift + クリックで複数選択）
2. **MoleculeTools** → **Save Selection as Molecule...** を選択
3. 分子名と単位胞中の分子数を入力
4. **OK** で ``data/<name>.toml`` として保存

Global Element Substitution ダイアログ
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- **Old Symbol**: 置換元の元素記号（既存元素から選択）
- **New Symbol**: 置換先の元素記号を入力
- 全ての該当原子が一括で置換されます

Molecule Substitution ダイアログ
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- **Molecule Index**: 置換対象の分子インデックス
  （原子を選択していれば自動設定）
- **New Molecule**: 置換先の分子名をドロップダウンから選択

Molecule Atom Substitution ダイアログ
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

特定の分子の全原子を新しい元素リストに置き換えます。

- **Molecule Index**: 対象の分子インデックス（原子選択時は自動設定）
- **New Symbols**: 新しい元素記号のリスト。コンパクト表記（``Si6O6`` 等）も使用可能
- 原子数は変わらず、元素記号のみが変更されます

Individual Atom Substitution ダイアログ
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

分子内の特定の 1 原子だけを別の元素に置き換えます。

- **Molecule Index**: 対象の分子インデックス（原子選択時は自動設定）
- **Atom Index**: 分子内の原子インデックス（0 始まり）
- **New Symbol**: 置換先の元素記号

Batch Element Substitution ダイアログ
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

複数の元素置換ルールをまとめて定義・実行できます。

- 各行で「置換元の元素 → 置換先の元素」を指定
- **+** ボタンで行を追加、**x** ボタンで行を削除
- 例: C→Si と H→F を同時に実行可能
- **OK** で全ルールが一括適用されます

Build Supercell ダイアログ
~~~~~~~~~~~~~~~~~~~~~~~~~~

現在の構造を繰り返し配置してスーパーセルを構築します。

- **a, b, c**: 各軸方向の繰り返し数を指定（整数）
- 格子ベクトルと原子座標が繰り返し数分だけ拡張されます

Move Molecule/Atoms ダイアログ
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

選択した原子や分子を平行移動します。

- **対象**: 「分子グループ全体」または「選択原子のみ」を選択可能
- **移動量 (X, Y, Z)**: 各軸方向の移動量をÅ単位で入力
- **+/- ボタン**: 微調整ボタン（押し続けで連続操作可能）
- **Step**: 移動ステップ幅のプリセット（0.01 / 0.1 / 0.5 / 1.0 Å）
- **Apply**: 現在の移動量を適用、 **Reset**: 初期位置に戻す

Rotate Molecule/Atoms ダイアログ
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

選択した原子や分子を重心周りに回転します。

- **対象**: 「分子グループ全体」または「選択原子のみ」を選択可能
- **トラックボール**: マウスドラッグで直感的に回転操作
- **α(X), β(Y), γ(Z)**: Euler 角を度単位で入力
- **+/- ボタン**: 微調整ボタン（押し続けで連続操作可能）
- **Step**: 回転ステップ幅のプリセット（1 / 5 / 15 / 45 / 90°）
- **Apply**: 現在の回転を適用、 **Reset**: 初期配向に戻す

Select by Element ダイアログ
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

元素ごとのチェックボックスで原子を選択します。

- 各元素にチェックボックスと原子数を表示
- チェックの変更で **リアルタイムに選択が更新** されます
- **モード**: Replace（既存の選択を置換）/ Add（既存の選択に追加）

Select by Molecule ダイアログ
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

分子グループ（mol_id）単位で原子を選択します。

- 各グループにチェックボックス、カラースウォッチ、原子数を表示
- **リアルタイムプレビュー** で選択状態が即座に反映されます
- **モード**: Replace / Add

Select by Sphere ダイアログ
~~~~~~~~~~~~~~~~~~~~~~~~~~~

選択中の原子を中心に、指定半径内の原子を一括選択します。

- **半径スライダー**: ドラッグで半径を調整（リアルタイムプレビュー）
- 選択範囲内の原子数と元素内訳を表示

Atom Appearance パネル
~~~~~~~~~~~~~~~~~~~~~~~~~~~

**View Settings** → **Atom Appearance...** から開くパネルです。3 つのタブがあります:

**Color Mode タブ**:

- **Default (by element)**: 元素ごとの標準色（jmol カラー）
- **By molecule group**: ``mol_id`` に基づき分子グループごとに色分け（20色を循環使用）
- **By tag**: タグ値に応じた色分け
- カスタム配列がある場合、追加の色モードが自動的に表示されます

**Element Colors タブ**:

- 構造中の各元素について個別に色を変更可能
- **Change...** ボタンでカラーピッカーを表示
- **Reset to Default** で jmol デフォルトに戻す

**Size タブ**:

- **Atom Size Scale**: 全体の原子サイズスケール（0.1〜3.0、スライダーで調整）
- **Per-Element Radius Override**: 元素ごとの共有結合半径を個別に変更

Cell Parameters ダイアログ
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

**MoleculeTools** → **Cell Parameters...** から開きます。

- **Lattice lengths**: a, b, c（Å 単位）を表示・編集
- **Lattice angles**: α, β, γ（度単位）を表示・編集
- **Lattice vectors**: 現在の格子ベクトル（読み取り専用）
- **Volume**: 格子体積（Å³）
- **Apply**: 入力値で格子を更新（原子座標はスケーリング）

Export ダイアログ
~~~~~~~~~~~~~~~~~

- 出力先ディレクトリを選択
- 出力フォーマットを選択（QE / VASP / CIF / All）
- **OK** でエクスポート実行
