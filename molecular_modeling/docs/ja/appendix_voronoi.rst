Voronoi 最適化の詳細
====================

本ツールキットの中核機能である Voronoi セル IoU 最適化について、
アルゴリズムの詳細を解説します。

問題設定
--------

有機分子結晶や分子性固体のモデリングでは、単位胞中に配置された分子の
**配向**（向き）を適切に決定する必要があります。
本ツールキットでは、分子の重心を Voronoi 分割の母点として、
系の Voronoi セルと辞書（参照結晶）の Voronoi セルの **幾何学的重なり**
を最大化することで最適な配向を自動的に決定します。

ここでの「系（system）」とは実際に構築したスーパーセル、
「辞書（dictionary）」とは参照となる単結晶構造を指します。

Voronoi セルとは
----------------

結晶中の各分子サイトの重心を母点として Voronoi 分割を行うと、
空間が各サイトに「最も近い」領域に分割されます。
この領域が Voronoi セル（ボロノイ多面体）です。

.. code-block:: text

   Voronoi セルの性質:
   - 各母点に対して 1 つの凸多面体が対応
   - 全セルの体積の合計 = 単位胞体積（空間を隙間なく充填）
   - セルの形状は分子間の相対位置で決まる

本ツールキットでは、周期境界条件を考慮した Voronoi 分割を行います。
具体的には、±1 セル分のイメージ（27 個の周期イメージ）を生成してから
SciPy の半空間交差法（HalfspaceIntersection）で Voronoi セルの頂点を
計算しています。

IoU（Intersection over Union）
------------------------------

IoU は 2 つの立体の重なり度合いを表す指標で、0 から 1 の値をとります。

.. code-block:: text

                  交差体積（Overlap）
   IoU = ──────────────────────────────────
          V_sys + V_dict - 交差体積

   IoU = 1: 2 つの Voronoi セルが完全に一致
   IoU = 0: 2 つの Voronoi セルが全く重ならない

ここで:

- **V_sys**: 系（スーパーセル）の Voronoi セル体積
- **V_dict**: 辞書（参照結晶）の Voronoi セル体積（スケーリング後）
- **交差体積**: 2 つのセルが重なる部分の体積

交差体積の計算には、系と辞書の両方の母点を統合した Voronoi 分割を行い、
参照点に対する統合セルの体積を求めます。
これは V_sys と V_dict の交差体積に相当します。

サイトごとの最適化手順
----------------------

最適化は各分子サイトについて独立に行われます。
1 サイトあたりの処理は以下の 5 ステップです。

ステップ 1: 系の Voronoi セル体積の計算
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

スーパーセルの全分子重心を母点とし、対象サイトの重心における
Voronoi セル体積 V_sys を計算します。

.. code-block:: text

   入力: スーパーセル格子 A_sys, 全分子の重心座標
   出力: V_sys (Å³)

系の Voronoi セルは最適化を通じて変化しません（配向を変えても
重心位置は変わらないため）。

ステップ 2: 辞書の Voronoi セル体積の計算
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

辞書（参照結晶）の格子ベクトルと重心を使い、辞書側の
Voronoi セル体積 V_dict を計算します。

.. code-block:: text

   入力: 辞書格子 A_dict, 辞書の重心座標
   出力: V_dict (Å³)

ステップ 3: 体積スケーリング
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

系と辞書の Voronoi セル体積が異なる場合（混合結晶など）、
辞書の格子と重心に均一スケーリングを適用して体積を合わせます。

.. code-block:: text

   スケール係数: s = (V_sys / V_dict)^(1/3)

このスケーリングにより、辞書の Voronoi セルの体積が系のそれと
同じになります。立方根を使うのは、3 次元の均一スケーリングでは
体積が s³ 倍になるためです。

ステップ 4: Euler 角の最適化
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

辞書の Voronoi セルを回転させ、系の Voronoi セルとの IoU を
最大化する Euler 角 (α, β, γ) を探索します。

**粗いグリッドサーチ（Phase 1）**:

.. code-block:: text

   α, β, γ それぞれを [-180°, 180°] の範囲で 13 分割
   → 13 × 13 × 13 = 2,197 通りの組み合わせを評価
   → 最も IoU が高い角度を初期解として記録

**Nelder-Mead 精密化（Phase 2）**:

.. code-block:: text

   グリッドサーチの最良解を初期値として Nelder-Mead 法で精密化
   - 目的関数: f(α, β, γ) = 1 - IoU（最小化）
   - 角度許容誤差: 0.001°
   - IoU 許容誤差: 0.001
   - 最大反復回数: 2,000
   - 最大関数評価回数: 10,000

Nelder-Mead 法は微分を使わない直接探索法であり、
IoU のような微分が困難な目的関数に適しています。

Euler 角の回転規則:

.. code-block:: text

   回転順序: XYZ（外因性）
   - α: X 軸周りの回転
   - β: Y 軸周りの回転
   - γ: Z 軸周りの回転

   回転行列 R = R_z(γ) × R_y(β) × R_x(α)

ステップ 5: 原子座標への適用
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

最適化された回転角とスケールを、対象サイトの全原子の座標に適用します。

.. code-block:: text

   各原子の新座標:
     pos_new = p_com + s × R × (pos_old - p_com)

   p_com: サイトの重心
   s:     スケール係数（ステップ 3）
   R:     最適回転行列（ステップ 4）

回転とスケーリングは重心を中心に行われるため、
分子の重心位置は変わりません。

辞書の Voronoi セルの構築方法
-----------------------------

辞書の Voronoi セルは以下の手順で構築されます:

1. 辞書の重心から参照分子（``voronoi_ref_id``、デフォルト 0）を原点に移動
2. Euler 角 (α, β, γ) で回転
3. スケール s で均一拡縮
4. 系の対象サイトの重心位置に平行移動
5. 辞書格子も同じ回転・スケールを適用し、±1 セル分のイメージを生成
6. 系と辞書の全母点から統合 Voronoi 分割を実行

この手順により、辞書の Voronoi セルが系の座標空間に配置され、
IoU の計算が可能になります。

体積タイリング検証
------------------

最適化後に、Voronoi セルの体積合計がスーパーセル体積と一致するか検証します。

.. code-block:: text

   検証条件:
     |ΣV_i - V_cell| ≤ abs_tol  または  |ΣV_i - V_cell| / V_cell ≤ rel_tol

   デフォルト許容値:
     abs_tol = 1e-6 Å³
     rel_tol = 1e-3（0.1%）

この検証に通らない場合、Voronoi 分割に問題がある可能性があります
（分子の配置が密すぎる、格子が極端に歪んでいるなど）。

最適化結果の解釈
----------------

最適化の結果は ``system.info`` に格納され、GUI の
**Pipeline** → **Show Optimization Results** で確認できます。

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - 出力項目
     - 意味
   * - IoU
     - 系と辞書の Voronoi セルの重なり度合い（0〜1）。1 に近いほど、辞書の分子配向が系で良く再現されている
   * - α, β, γ
     - 最適化された Euler 角（度）。辞書の分子配向に対する回転量
   * - scale
     - 体積スケーリング係数。1.0 なら系と辞書の Voronoi 体積が同じ。1 より大きい場合、系のサイトが辞書より広い

**IoU の目安**:

- **0.9 以上**: 辞書の配向が系で非常に良く再現されている
- **0.7〜0.9**: おおむね良い再現
- **0.7 未満**: 系と辞書の環境が大きく異なる（混合結晶での異種分子の影響など）

可視化（Voronoi オーバーレイ PNG）
----------------------------------

最適化結果は 3D 画像として可視化されます:

- **青い半透明多面体**: 系の Voronoi セル（実際の空間分割）
- **赤い半透明多面体**: 辞書の Voronoi セル（最適化で回転・スケールされた参照セル）
- **オレンジの半透明多面体**: 2 つのセルの交差部分

IoU が高いほど、青と赤の多面体がよく重なり、ほぼ同じ形状になります。
